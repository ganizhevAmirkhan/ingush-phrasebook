# Workbench — ING → RU (смысловой перевод)

## Порядок работы

1. **ING** — оригинал из книги  
2. **RU** — смысловой перевод (черновик → правка)  
3. **phrases[]** — куски ING + RU смысл  
4. **words[]** — слова ING → RU  
5. **status** — `draft` | `verified`

Так удобнее для глубокого смысла: не подгонять ингушский под готовый русский, а идти от оригинала.

## UI

`http://localhost:8787/tools/corpus-align.html`

- **ING → предложения** — вставить кусок книги и разрезать  
- **Разобрать слова ING** — токены + подсказки из Тариева/корпуса  
- словарь справа ищет сначала по ингушскому

## Экспорт

```bash
npm run workbench:export
```
