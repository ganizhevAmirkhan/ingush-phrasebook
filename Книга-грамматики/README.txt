Книга грамматики ингушского языка
==================================

Путь:
  C:\Users\admin\Desktop\РАЗГОВОРНИК\ingush-phrasebook-main\Книга-грамматики

Структура папок:
  00-Термины      — шпаргалка терминов (ингушский ↔ арабский)
  01-Оглавление   — введение, оглавление книги
  02-ЦӀердош      — имя существительное
  (далее: Хандош, Алп…)

Формат главы (по образцу Сибавайхи):
  Матн    — текст автора; примеры только на ингушском
  Шарх    — объяснение
  Масалаж — примеры (شواهد)

Три столпа речи:
  ЦӀи     (имя, اسم)
  Хандош  (глагол, فعل)
  Алп     (служебный элемент, حرف)

Русские названия: Оглавление, Глава (не Китаб, не Баб).

Падежи:
  дужар   — падеж
  дужараж — падежи
  цӀера дужар, ветта дужар, доала дужар…
